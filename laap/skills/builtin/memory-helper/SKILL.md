# Memory Helper Skill

Use this skill when you need to remember important information across conversations or help the user organize their context.

## Key Patterns

1. **Save important facts**: When the user shares personal info, preferences, or project context, store it
2. **Recall relevant context**: Before starting tasks, check if there's saved context
3. **Organize by domain**: Group related information together for easier retrieval

## Memory Operations
- Use the memory tool to store key-value information
- Tag memories for easy filtering
- Review memories at the start of each session
